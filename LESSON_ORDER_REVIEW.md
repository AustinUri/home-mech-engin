# Lesson Order Review

This version rebuilds the lessons around learning prerequisites:

1. Explain normal operation first.
2. Identify the main parts and their purpose.
3. Teach the measurement or formula needed.
4. Only then introduce failures and diagnosis.

Main fixes:

- The first module no longer asks engine-diagnosis questions.
- Engine diagnosis now appears only after lessons about four strokes, engine needs, gasoline vs diesel, and basic combustion conditions.
- Each lesson includes prerequisite knowledge and source labels.
- The intro test was changed so it tests general technical thinking, not engine diagnosis.
- Math exercises were re-linked to the correct lesson IDs.

Sources referenced in lesson labels include the same school resources already listed in the website:
OpenStax, MIT OCW, Automotive Textbook, ASE Study Guides, How a Car Works, WeberAuto, Mercury Marine, BoatUS, Marine Diesel Basics, and Engineering ToolBox.
