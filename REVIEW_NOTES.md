# Site Review Notes

## What was weak before
- Some lessons were still too short and felt like concept cards instead of real lessons.
- Mathematical practice existed mostly in tests, not inside the lessons where the learning happens.
- Diagrams were useful but not school-like enough for problem solving.
- Tests had calculations, but the calculation questions did not show diagrams.
- The lesson page needed a clearer learning flow: explanation → diagram → steps → example → math practice → mini quiz.

## What was improved
- Added more lessons across engines, electricity, diagnostics, sensors, drivetrain, suspension and portfolio documentation.
- Added school-style math exercises with diagrams and step-by-step solutions.
- Added diagrams to calculation questions in the tests.
- Improved lesson layout width and readability.
- Added stronger light-mode overrides to reduce dark-mode visual issues.
- Kept all code comments in English.

## Next recommended improvements
- Add user-entered answers for the math exercises inside lessons.
- Add progress tracking per lesson, not only per module.
- Add exportable study notes or PDF summaries.
- Add animated diagrams for current flow, four-stroke engine movement and gear ratio.
