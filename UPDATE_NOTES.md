# Update notes

## What changed

- Added detailed lessons for every module.
- Improved the visual design with a garage/blueprint theme.
- Forced the app to stay in a light theme so OS/browser dark mode will not make it unreadable.
- Added more formulas across electricity, mechanics, gears, hydraulics and engines.
- Added more serious tests with numeric calculation questions.
- Kept code comments in English.

## Run

```bash
npm install
npm run dev
```

If PowerShell blocks npm, use Command Prompt or run:

```powershell
npm.cmd install
npm.cmd run dev
```
